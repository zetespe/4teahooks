# 4tea Hooks — notes for contributors and AI assistants

This repository will be public. Treat every commit as published.

## Commits

- No attribution trailers: no `Co-Authored-By`, no `Claude-Session`, no "Generated with" lines.
- No links to chats, sessions or conversation history anywhere (commits, code, docs, PRs).
- Commit identity: `zetespe <zetespe@users.noreply.github.com>`.

## Never commit

- Personal data, real names, email addresses.
- Tokens, API keys or secrets of any kind. The GoatCounter count URL is public by design
  and needs no token; dashboard access stays in the GoatCounter account.
- Copyrighted patterns from other designers. Test fixtures use patterns written for this repo.
- Users' own patterns or project data.
